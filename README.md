## Selected projects

### [BookingSystem · Mietek Customs](https://github.com/stanislaw-kopec/BookingSystem)

A car workshop management system covering appointment requests, repairs, vehicle pickup and PDF invoices.

- Transactional booking with PostgreSQL locks to protect daily capacity during concurrent requests.
- Role-based access for customers, mechanics and administrators; persisted invoice snapshots.
- Integration tests with PostgreSQL and Testcontainers, plus GitHub Actions and Docker Compose.

**Java · Spring Boot · Spring Security · PostgreSQL · Flyway · React · TypeScript**

### [WatchWeb](https://github.com/stanislaw-kopec/WatchWeb)

A community portal for watch enthusiasts with a searchable catalog, reviews, comments and content moderation.

- JWT authentication with refresh tokens and role-based authorization.
- Catalog filtering and pagination with Spring Data JPA; moderation workflows and author notifications.
- Flyway migrations and integration tests using PostgreSQL with Testcontainers.

**Java · Spring Boot · PostgreSQL · JWT · Testcontainers · React · TypeScript**

### [Car Excise Tax Calculator](https://github.com/stanislaw-kopec/CarExciseTaxCalculator)

A web application for estimating Polish car import excise tax, integrating NBP exchange rates with calculation logic and unit tests.

**Java · Spring Boot · Thymeleaf · NBP API · JUnit**
